# Saanvi Fashion Store

Build a polished, premium e-commerce website for a ladies' suit/fashion store.

Design inspiration: Flipkart-style Indian e-commerce UX, but NOT a copy. Make it feel modern, clean, premium and specifically designed for women's clothing.

Pages/features:

- Home page with a professional header, search bar, category navigation, hero banner and attractive product sections

- Categories: Suits, Kurtis, Salwar Suits, Anarkali, Party Wear, New Arrivals

- Product listing page with filters for price, size, colour, category and sorting

- Product detail page with large image gallery, product name, price, discount, sizes, colours, description, ratings/reviews, delivery information, Add to Cart and Buy Now

- Shopping cart with quantity controls, price summary and checkout button

- Checkout page with customer details, address, order summary and payment placeholder

- Login/signup UI

- Customer profile with orders and wishlist

- Responsive mobile-first design

Use realistic Indian women's suit products with high-quality fashion imagery, realistic ₹ pricing, discounts, sizes and product information. Do NOT use generic placeholder-looking cards.

Visual style:

- Premium fashion-store aesthetic

- Clean white/light background

- Elegant typography

- Subtle shadows and rounded cards

- Strong product photography

- Tasteful pink/maroon/rose accents

- Spacious layout

- Smooth hover effects and micro-interactions

- Professional enough to look like a real commercial fashion store

Important:

- Make every page visually polished and consistent.

- Make navigation, search, filters, cart, wishlist and product interactions actually work on the frontend.

- Use reusable components and clean responsive React code.

- Do not overcomplicate the design.

- Focus on making the website look like a real, trustworthy Indian online clothing store rather than a generic AI-generated template.

- Use a temporary brand name "Saanvi Fashion" that can easily be changed later.
